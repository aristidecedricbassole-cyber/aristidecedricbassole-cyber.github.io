## Galerie photographique (section Projets)

Carrousel de **12 photos réelles** (`assets/galerie/`, optimisées à 1300 px) :

- Institutionnel : cérémonie officielle, cérémonie de promotion
- Studio : portrait beauté, mode & direction artistique
- Drone : grand rassemblement, mariée vue du ciel
- Concert : live sur scène, scène & lumières
- Mariage : détails de cérémonie
- Culture : tenue traditionnelle, couple en tenue traditionnelle
- Portrait : forces de défense

Fonctions : défilement automatique (6 s), flèches, points de navigation,
balayage tactile, clavier (← →), lightbox avec navigation, pause au survol.
Les photos sont affichées **entières** (`object-fit: contain`) sur un fond
flouté, avec une hauteur de cadre animée selon le format (portrait / paysage).

## Projet réel — Bookcamp FILO

Reportage photo de **6 images** pour préparer le **bookcamp des amis de la Foire
Internationale du Livre de Ouagadougou (FILO)**, dans `assets/filo/` :
portrait avec l'ouvrage « Relations Publiques en Afrique », lecture, prise de
notes, partage de livres, lecture en plein air et portrait noir & blanc.

Galerie dédiée avec défilement automatique, flèches, points, balayage, lightbox.
